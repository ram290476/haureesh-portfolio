SMASH Scholar.

SMASH at UC Berkeley · Jul–Aug 2025

Overview

In July–August 2025 I was a SMASH scholar in the residential STEM program at UC Berkeley, one of 100 scholars that year. A certificate marks completion of the residential program in 2025.

My Role

I was a scholar in the program. On my own I built a top-down chase game in Godot. With my team I built the HTML and CSS front end of a website that helps people find community support services.

Technologies/Tools

  • Python
  • HTML
  • CSS
  • Godot

Process/Build

During the program I built projects in Python, HTML, and game design. The individual project was the Godot chase game. The team project was the front end of the community support site.

Outcomes/What I Learned

I completed the SMASH residential program. The builds from the summer are the Godot chase game and the team site that helps people find community support services.
