Project

Teleoperated SO-101 Robot Arm.

Personal project · May–Jul 2026

Overview

From May to July 2026 I built a 6-axis SO-101 robot arm on my own. I 3D printed the structural parts, then integrated the servo motors, wiring, and controller hardware into a working arm. After that, I programmed teleoperation in Python with Hugging Face LeRobot so I could drive the arm myself.

My Role

This was an independent personal project, May–Jul 2026. I was the sole builder: printing, wiring, and programming.

Technologies/Tools

  • Python
  • Hugging Face LeRobot
  • 3D printing
  • Servos and controller hardware

Process/Build

I 3D printed the structural parts, integrated the servos, wiring, and controller, and then set up teleoperation in Python with Hugging Face LeRobot.

Outcomes/What I Learned

The result is a complete, teleoperated SO-101 arm that I can drive myself.
